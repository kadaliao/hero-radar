# 英雄雷达 · MARVEL × DC

漫威和 DC 角色识别特训：看头像、认道具、猜剪影，再到能力、真名、宿敌和线索推理。每答对一题，背景和音乐都会叠上一层，越答越燃。

在线试玩：https://hero-radar.vercel.app

玩法和节奏参考了 [dopa-drill](https://github.com/grmchn/dopa-drill)（一款越解越嗨的计算练习游戏）。

## 特点

- 73 位角色（漫威 39、DC 34），48 件标志道具，全部配了原创的扁平 SVG 头像和道具图标，没有使用官方图片
- 17 项技能组成技能树：看脸认人、标志道具、剪影挑战、真实身份、超能力、宿敌、团队、配色、撞衫对决（快银还是闪电侠？死侍还是丧钟？）、线索追踪等
- 选错只标“差一点”，换一个再选，不会结束；全部答完就是 100 分
- 连击越高能量涨得越快，画面依次叠加网点、速度线、漫画拟声词、闪电和彩纸
- 首答正确率达到 80% 可进入 60 秒加时赛，第 k 题加 10+5k 分
- 最近 6 题首答正确 5 题即可掌握一项技能，之后还能升到 ★★★；14 天没答对会生锈
- 错题复习、角色图鉴（未解锁的显示为剪影）、每日任务、成就
- 音乐和音效全部由 Web Audio 实时合成，没有音频文件
- 单个 HTML 文件，零依赖；记录只保存在本机浏览器的 localStorage

## 本地运行

直接用浏览器打开 `index.html` 即可。也可以起一个静态服务：

```bash
python3 -m http.server 8000
```

电脑上可以用数字键 1–4 作答，回车继续。

## 部署

仓库根目录就是静态站点，Vercel、GitHub Pages、Cloudflare Pages 等都可以直接托管，无需构建。
